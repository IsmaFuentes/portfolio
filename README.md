# Portfolio

Portfolio personal desarrollado con React, TypeScript y Tailwind CSS. Presenta mi experiencia, formación y proyectos de software.

**Demo:** [portfolio en vivo](https://IsmaFuentes.github.io/portfolio)

## Secciones

- **Sobre mí:** perfil, formación y tecnologías.
- **Experiencia:** trayectoria profesional y responsabilidades.
- **Proyectos:** trabajos destacados y casos de estudio de análisis de datos para piragüismo y automatización web para DISPREU.

El sitio utiliza una interfaz oscura, galerías de imágenes ampliables y resaltado de código.

## Tecnologías

- React 19, TypeScript y Vite 7
- Tailwind CSS 4 y React Router 7
- Highlight.js para el código C#
- GitHub Pages para el despliegue

## Estructura

```text
src/
  assets/       Imágenes y recursos
  components/   Componentes reutilizables
  pages/        Secciones y casos de estudio
  types/        Tipos de TypeScript
```
